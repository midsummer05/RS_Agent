# QA 召回率评测

QA 评测与遥感分割 IoU 分开运行。它衡量质量门禁是否能标记**应拦截**的结果：

```text
召回率 = 被标记的应拦截案例 / 全部应拦截案例
精确率 = 被标记且确有异常的案例 / 全部被标记案例
```

固定案例位于 `data/qa_cases/`：空掩膜、主导掩膜、无效几何、无效输入，以及两个正常对照。运行：

```powershell
.venv/Scripts/python.exe scripts/evaluate_qa.py
```

当前六例控制样本的召回率和精确率均为 1.0。这验证门禁逻辑及报告链路，不代表真实遥感异常数据上的泛化效果；后续应补充真实 CRS、矢量拓扑、文件损坏和低质量影像样本。
